# PRD: 닌자거북의홈

## 목표

방문자가 공개 앱을 한눈에 보고 자신의 플랫폼에 맞는 다운로드·신고·개인정보·지원
링크를 찾게 한다. 후원 현황과 사용 내역을 투명하게 공개한다.

## 기능

| ID | 기능 | 설명 |
| --- | --- | --- |
| F-001 | 앱 목록 | Mac/iPhone 그룹, 플랫폼 필터, 미출시 앱 표시, 퇴역 앱 제외 |
| F-002 | 앱 링크 | 다운로드, GitHub Issue Form 신고, privacy, support (레지스트리 파생) |
| F-003 | 후원 현황 | 총액·통계·월별 막대·이력. `data/support.ts`가 원천 |
| F-004 | 사용 내역 | 분류 바·장부·영수증 링크·남은 금액 |
| F-005 | 후원 서랍 | Fairy(국내)/Buy me a coffee(해외) 링크. URL 미설정 시 숨김 |
| F-006 | 다국어 | ko/en, `/ko`·`/en` 라우트와 로케일 리다이렉트 |

## 비기능

- 정적 프리렌더, 운영 API 없음, 방문자 데이터 수집 없음.
- OKLCH 토큰, system-ui 글꼴, 외부 런타임 요청 없음.
- 이메일 신고 경로 없음(법적 페이지 연락처 제외).
- 320px 이상에서 가로 스크롤 없음.
