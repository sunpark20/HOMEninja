# 앱마을 UI 가이드

## 방향

「모여봐 앱마을」은 밝은 낮의 시골 마을과 종이 동화책의 질감을 가진다. 첫
화면에서 방문자는 앱 10개가 있다는 사실과 각 앱의 플랫폼을 즉시 이해해야
한다. 모바일 세로 흐름이 기준이며 데스크톱은 같은 구조에 여백만 확장한다.

## 토큰

모든 색은 `app/globals.css`의 OKLCH 토큰으로 사용한다.

| 역할 | 토큰 |
| --- | --- |
| 제목·나무껍질 | `--c-title`, `--c-heading`, `--v-bark` |
| 본문·보조 | `--c-body`, `--c-secondary`, `--c-meta` |
| 종이 | `--v-paper`, `--v-paper-deep` |
| 하늘·언덕·잔디 | `--v-sky`, `--v-hill-far`, `--v-hill-near`, `--v-grass` |
| 행동 | `--v-orange`, `--v-orange-dark` |
| 테두리 | `--c-border`, `--c-divider` |

sky 팔레트만 채택한다. meadow/mint 토글이나 숨겨진 테마 토큰은 만들지 않는다.
배경·잎·간판은 종이와 풍경의 면으로 표현하고 텍스트에 그라디언트를 적용하지
않는다.

## 구조

- 헤더: 앱마을 도장, 짧은 내비게이션, 선택적 입주 버튼
- 히어로: `모여봐 앱마을`, 한 줄 약속, 마을 구경 CTA, 나무 흔들기 힌트
- 앱 숲: Mac 나무 4개, iPhone 나무 6개. 잎 카드는 처음부터 모두 노출
- 지면: 떨어진 잎 슬롯, 방문자의 집, 우편함, 제주택배비지원 그루터기
- 게시판: TMT 항목과 관리자 편집 진입점
- 상세 모달: 이름, 영문 이름, 한 줄 설명, 플랫폼/OS/버전, 다운로드, GitHub
  신고, 개인정보, 지원 링크

## 앱 잎과 상태

사실 필드는 `data/apps.generated.ts`, 색·이니셜·나무는
`data/village-visuals.ts`에서 읽는다. 잎 색은 앱 id에 고정하고 등록 순서나
버전 문자열을 표현 파일에 복사하지 않는다.

- released: 다운로드 버튼과 버전을 표시
- unreleased: 잎을 계속 보여주되 `곧 만나요`와 우편함 안내를 표시
- retired: 앱 숲 대신 그루터기에 표시하며 다운로드 링크를 제공하지 않음

## 접근성과 모션

- 잎과 모든 동작은 실제 `button` 또는 `a`로 키보드 접근 가능해야 한다.
- `aria-label`, `aria-expanded`, `aria-modal`, `aria-live`를 상태에 맞게 쓴다.
- 나무 흔들기 뒤 아직 떨어지지 않은 released 잎 하나를 지면에 보낸다. 미출시
  잎은 흔들어도 사라지지 않는다.
- 착지는 Web Animations API 또는 CSS keyframe으로 구현하며 지그재그 낙하와
  짧은 착지 반동만 허용한다. 이 반동은 정보 발견을 설명하는 유일한 모션 예외다.
- `prefers-reduced-motion: reduce`에서는 모션을 즉시 종료하지만 잎·다운로드·신고
  링크를 숨기지 않는다.

## 승인된 예외

프로젝트의 일반 금지 목록은 다음 두 가지를 제외하고 그대로 적용한다.

1. 잎 착지의 짧은 반동: 낙하라는 상호작용의 의미를 전달한다.
2. 간판·주요 버튼의 두 색 면 채우기: 종이 간판의 인쇄감을 위한 것이다.

gradient-text, `backdrop-filter`, 네온 글로우, 보라/인디고/시안 그라디언트,
배경 blur orb, 카드 안 카드, 좌우 컬러 스트라이프는 허용하지 않는다.

## 반응형 기준

| 폭 | 원칙 |
| --- | --- |
| 320–640px | 헤더 줄바꿈, 나무 세로 스택, 잎 2열, 시설 1열 |
| 641–900px | 나무 세로 스택, 시설 2열 |
| 901px 이상 | 두 나무 나란히, 시설 3열, 중앙 최대 폭 1180px |

어떤 폭에서도 페이지 가로 스크롤을 만들지 않는다.

## 금지 패턴

AI 랜딩 페이지처럼 보이는 균일한 둥근 카드, 모든 버튼의 동일한 강조,
장식만을 위한 숫자/배지, 의미 없는 모션, 숨겨진 콘텐츠, 외부 CDN 아이콘을
추가하지 않는다. 카드와 모달은 종이 테두리와 하드 섀도로 계층을 만든다.
